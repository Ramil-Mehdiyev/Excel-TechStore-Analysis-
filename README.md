# TechStore - Sales & Data Analysis Project (Excel)

This repository contains a comprehensive data cleaning, structuring, financial modeling, and advanced reporting project executed in Microsoft Excel for *TechStore*, an electronics retail network.

## 📊 Project Overview
As a Data Analyst at TechStore, the objective was to process a raw dataset of 1,000 sales transactions containing errors, missing values, and formatting inconsistencies, transforming it into a clean, dynamic, and interactive analytical model.

## 🛠️ Key Steps & Methodology
1. *Data Cleaning:* Removed leading/trailing spaces (TRIM), standardized text capitalization (PROPER), eliminated duplicate transaction IDs, handled missing values ("Naməlum"), unified date formats, and enforced data validation rules for payment methods.
2. *Data Structuring:* Generated dynamic Customer Codes (CONCATENATE, LEFT, MID), automated delivery notes, and formatted international phone numbers.
3. *Financial Calculations:* Integrated price lists using lookup formulas (XLOOKUP/VLOOKUP), calculated Total Revenue, Net Profit, Conditional Discounts (IF/AND), Credit Due Dates (EOMONTH), and Sales Weekdays (TEXT).
4. *Conditional Formatting:* Applied visual data bars for Net Profit and highlight rules for high-volume sales quantities ($\ge 8$).
5. *Advanced Pivot Tables & Dashboards:* Built multi-dimensional pivot tables for regional payment structures, category profit shares, monthly trends with Timelines, and a Top 10 Customer performance ranking.
